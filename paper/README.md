# Research Context

This repository contains the implementation and reproducibility materials for
the study **Confidence-Aware Guardrailed Agentic RAG for IoT Intrusion
Mitigation Planning** by Joy Dutta, Samara Mayhoub, Hossien B. Eldeeb, and Ali
Ismail Awad.

The work was prepared for [IFIP IoT 2026](https://ifip-iotconference.org/).
The repository focuses on the experiment: source code, configuration, standards
corpus, saved API records, machine-readable results, tests, and technical
documentation.

Article text and publication artwork are outside the scope of this repository.
The numerical evidence behind the study remains available under
[`reports/tables/`](../reports/tables/README.md), and each result is linked to
its source in
[`docs/results/RESULT_TO_ARTIFACT_MAP.md`](../docs/results/RESULT_TO_ARTIFACT_MAP.md).
