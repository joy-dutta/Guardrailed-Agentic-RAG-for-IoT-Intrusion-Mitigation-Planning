# Reports

This folder keeps the saved numerical evidence close to its plain-language interpretation:

- `tables/` contains the reference CSV and JSON results.
- `comprehensive_evaluation/` contains the expanded calibration, routing, planning, model-sensitivity, evidence-gate, and review results.

Use `python scripts/reproduce.py reports` for the reference analysis and `python scripts/reproduce.py journal-reports` for the expanded summaries. The broader explanation and claim boundaries are maintained once under `docs/results/` to avoid conflicting versions.
