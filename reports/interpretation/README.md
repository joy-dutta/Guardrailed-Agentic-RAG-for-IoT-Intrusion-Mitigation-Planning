# Interpretation

`RESULTS.md` is the detailed experiment narrative. It states what each result
supports, what it contradicts, and what remains untested.

`CONTRIBUTION_AND_PHYSICAL_IMPACT.md` translates terms such as dataset row,
coverage, escalation, evidence binding, and bounded intent into their meaning at
an IoT gateway or cloud security service.

Use these files together with `docs/results/CLAIMS_AND_LIMITATIONS.md` when
adapting the project description for another evaluation or deployment study.
