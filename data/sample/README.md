# Small Example Alert

`sample_alert.json` is a synthetic teaching example, not a CICIoT2023 row and
not part of the reference results. It shows the fields passed from a detector to the
retrieval and planning stages without requiring the large dataset.

Use `python scripts/reproduce.py smoke` for the no-data test path. Full detector
reproduction requires the verified CICIoT2023 CSV archive described in
`docs/dataset/DATA_CARD.md`.
