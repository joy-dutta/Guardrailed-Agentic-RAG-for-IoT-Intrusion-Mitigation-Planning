# Raw Input

Download the registered `CSV.zip` archive from the [official CICIoT2023 page](https://www.unb.ca/cic/datasets/iotdataset-2023.html) and place it here as `CICIoT2023_CSV.zip`.

The reference experiment used:

```text
Bytes:   1,430,268,604
SHA-256: E211E878D2F39226EA3A854683F91AE6175B628807EE96EEECB7A04A36A28DBD
```

`python scripts/reproduce.py bootstrap` checks both values before extraction. The archive is intentionally ignored by Git because of its size. No API key or website credential should be stored here.
