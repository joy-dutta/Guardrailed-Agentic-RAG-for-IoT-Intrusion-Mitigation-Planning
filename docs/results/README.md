# Result Documentation

- `RESULTS_IN_PLAIN_LANGUAGE.md` explains the results in a gateway or cloud
  security workflow.
- `CLAIMS_AND_LIMITATIONS.md` separates supported statements from out-of-scope
  claims.
- `RESULT_TO_ARTIFACT_MAP.md` links each result to its CSV/JSON source and Python
  module.

Exact values remain in `reports/tables/`; these documents explain their meaning.
