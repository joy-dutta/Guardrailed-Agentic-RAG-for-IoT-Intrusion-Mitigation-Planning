# Legal And Redistribution Notes

The MIT license applies to the original software in this repository. Dataset files, standards, and Python packages retain their publishers' terms.

[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) records the source and redistribution approach for CICIoT2023, NIST publications, IETF RFCs, ETSI EN 303 645, and software dependencies.

The repository includes the materials that can be redistributed with their notices intact. Where redistribution terms differ, the bootstrap script obtains the document from its official source and verifies its hash locally.
